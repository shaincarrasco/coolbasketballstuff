Live data

ESPN public API

Lineup Intelligence and Game Predictor run on real NBA games, box scores and rosters pulled from ESPN’s public API. A scheduled job refetches new games every morning, retrains both models and redeploys this site; the Predictor page also overlays live scores in your browser.

The Jumpshot Analyzer runs on synthetic demo clips until you feed it your own footage. Each project keeps a --source sample fallback and an nba_api loader. Fit scores and probabilities are for learning and demonstration only — not betting advice, nothing is guaranteed.
